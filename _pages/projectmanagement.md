## Time Schedules, Work Packages, Versioning, Documentation

Together with the project of creating my own <a href="https://laetitiaadam.github.io/spatialdatainfrastructure/">Spatial Data Infrastructure</a> I applied the techniques of project management. 
This included breaking the project down into work packages, assigning responsibilities, defining a time schedule with deadlines and deliverables. <br>

![Work Packages](/assets/images/pm_workpackages.png)

*The project is divided into several work packages (Own Figure)*<br>

Each work package has its own subtasks and deadlines. With each deadline I defined a final product that needs to be completed by then.

![Gantt Chart](/assets/images/pm_ganttchart.png)

*The Gantt Chart gives on overview of all deadlines (Own Figure)*<br>

To keep track of my work I used GitLab. In GitLab each task is assigned a date and milestone. The GitLab project also contains repositories for all files, code versioning and presentations. The Wiki is used to document the projects progress and work flow.

![GitLab](/assets/images/pm_issueboard.png)

*Issue board in GitLab highlighting the work progress* <br>
